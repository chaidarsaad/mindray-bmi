🩺 usgmindray.com – Website Penjualan Alat USG & Pelatihan
Deskripsi Singkat:

usgmindray.com adalah website yang dibangun menggunakan Laravel 12, Livewire, dan Filament, yang berfungsi sebagai platform penjualan alat USG, layanan pelatihan USG, dan publikasi artikel edukatif seputar dunia ultrasound.

Website ini ditujukan untuk klinik, rumah sakit, tenaga medis, dan individu yang ingin mendapatkan akses ke produk-produk USG berkualitas serta pelatihan profesional dari tim bersertifikat.

🌟 Fitur Utama:
🛒 Katalog alat USG dengan detail spesifikasi & harga

📆 Halaman pendaftaran pelatihan USG (dengan jadwal)

✍️ Blog / Artikel edukatif seputar ultrasound

📦 Manajemen produk, artikel, kategori, dan pendaftaran via Filament Admin

📥 Formulir kontak & pemesanan

🔍 Fitur pencarian produk dan artikel

🛠️ Teknologi Digunakan:
Laravel 12

Livewire (komponen dinamis tanpa JS manual)

Filament 3.x (untuk dashboard admin)

MySQL / MariaDB

Bootstrap (untuk tampilan front-end)
